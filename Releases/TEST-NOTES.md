# What's new in the current test release (shown in the Telegram post; plain lines, no headings below)
• Tools has a side menu: Remote, Sound, PC, Files and Terminal
• Remote: clearer buttons, a volume rocker, Task view and Show desktop
• Sound: the PC's volume, Play everywhere, which speaker the PC uses, phone as speaker or mic
• PC: live graphs like Task Manager (CPU, memory, disk, network, GPU)
• Files: grid view, icons for Desktop, Music and more, and a tappable path
• Terminal: pick PowerShell, CMD, WSL or Git Bash and type straight into it
• Home: redesigned, with your PC's stats and every tool one tap away
• PC Remote: USB icon on cable, "PC screen off" option, click circle now optional
• Sharing to Linc now shows a sending notification
• PC app: see-through Mica look, fits small windows, Device page with screen time, wallpaper, colours and phone sound
