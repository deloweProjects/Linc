# AGENTS-REGISTRY.md — the coding agents & how the master runs them

**Naming:** the project / workspace is **`yellow`** (`<repo-root>/`); the **product** being
built — the code the agents edit — is **`Linc`**, under `yellow/Linc/`. Every agent must know both.

The master (orchestrator) does the thinking and writes prompts; **coding agents write the production
code and run tests, one at a time.** This file is the master's guide to each agent and the ledger of
who did what. Enforced behavioral rules live in `Vibe/agent\{AGENTS,GEMINI,GUARDRAILS}.md`; the nemo
worker's guide is `Vibe/agent/NEMO.md`.

## The golden rules (apply to every agent)
- **VERIFY, DON'T TRUST.** An agent's report is a claim, not evidence. Spot-check the actual files,
  diffs and timestamps every session — every real defect this project caught was found that way, not
  by reading a green report. Full doctrine + worked examples: `ORCHESTRATOR.md` → "VERIFY, DON'T
  TRUST". This applies to **every** agent and to **any** model behind opencode.
- **A resuming master, first thing:** read `Vibe/master/` + `BRAIN.md` (know the state yourself — never
  ask the owner about internal task IDs), give a next-task summary, then **ask which agent is resuming**
  (Antigravity / Claude Code / nemo — pure console or unpure-via-Claude). That's the only start question.
- **Agents have NO memory** — every task is a fresh, self-contained prompt, even with the same agent.
  So there's no "continue vs fresh" to ask; always pack full context into the prompt.
- **One agent active at a time.** Its working-doc folder under `Vibe/agent/` is the live one; the
  master syncs the other folder only at a switch.
- **Agents do CODE + TESTS only.** The master keeps all docs current.
- **Never hijack the machine to verify:** no real cursor movement (`SetCursorPos`/`mouse_event`), no
  autonomous phone taps while the owner may be working — those go back as a numbered manual test script.
- **Smallest possible change; no scope creep; no stray files; protocol is sacred (bump `PROTOCOL.md` first).**
- Since the reorg (2026-07-26) the rules no longer auto-load from the repo root — **give every agent
  absolute paths** to `Vibe/agent/` and restate the critical rules in the prompt.
