## Part C — Packaging: one installer `Linc-Setup-<ver>.exe`, plus a portable zip

The current build is a self-contained folder: ~459 files, ~434 MB unpacked, ~173 MB zipped
(`Beta.pubxml`; .NET 8 + Windows App SDK self-contained, bundled scrcpy/adb, `Assets\companion.apk`,
VC++ redist DLLs). People need one file to double-click.

1. **Installer technology: Inno Setup 6** (free, standard, scriptable, LZMA2 compression, no admin
   needed) unless you find a concrete blocker — then stop and ask. Do NOT switch to MSIX (the app is
   `WindowsPackageType=None` on purpose, and MSIX needs signing). If Inno Setup isn't installed, ask the
   owner to install it (he installs tools himself) rather than downloading it yourself.
2. **What the installer does:** per-user install to `%LOCALAPPDATA%\Programs\Linc` (no UAC); Start
   menu shortcut; optional desktop shortcut; optional "Start Linc with Windows" (reuse the app's own
   startup setting, don't add a second mechanism); app icon from `Assets/AppIcon.ico`; licence page
   (repo `LICENSE`) plus third-party notices (scrcpy/adb Apache-2.0 `NOTICE`, the Google Quick Share
   protos); "Launch Linc" on finish. **Upgrade in place:** stable `AppId`, closes a running Linc
   gracefully first (`CloseApplications`), keeps the user's data in `%LOCALAPPDATA%\Linc` (settings,
   logs, caches, the VB-CABLE pack). **Uninstall:** removes the program; asks whether to also delete
   `%LOCALAPPDATA%\Linc`; restores anything Linc changed (default mic / Voice Access mic, tablet-mode
   scale — `PcVoiceAccess.RestoreAllMics`, `PcTabletMode.RestorePending`; give the exe a
   `--restore-and-exit` switch the uninstaller can call). It does not uninstall VB-CABLE (VB-Audio's own
   uninstaller does that; say so).
3. **Self-update uses the installer.** `UpdateCheckService.DownloadAndVerifyAsync` + `LaunchInstaller`
   already verify SHA-256 then launch the download. Point `update.json`'s `desktop.url` at
   `Linc-Setup-<ver>.exe` and launch it silently (`/VERYSILENT /SUPPRESSMSGBOXES /CLOSEAPPLICATIONS
   /RESTARTAPPLICATIONS` or equivalent), so an update is: download → verify → install → Linc restarts.
   Old installs that only know zips must still be offered something sane (check what `LaunchInstaller`
   does with a zip today and document the transition).
4. **Portable zip** stays as a second asset for people who don't want an installer.
5. **Size:** report installer size. Try the cheap wins only — LZMA2/solid compression, excluding
   files that aren't needed at runtime (`.pdb`, duplicate runtimes, unused locales) — and prove each
   exclusion with a clean-PC style launch test (`tools/cleanroomsim` exists — see what it checks). No
   trimming/AOT experiments on the WinUI app.
6. **Signing:** there is no code-signing certificate. Unsigned installers trigger SmartScreen
   ("Windows protected your PC" → More info → Run anyway). Make the build accept an optional cert
   (`signtool` step that runs only if a cert thumbprint/env var is set), document the SmartScreen step
   for users, and tell the owner what a cert costs/needs. Do not buy or self-sign anything.
7. **One release script:** `Linc\tools\release.ps1 -Version 1.0.0.11 -DisplayName "1.0.0-beta.11"`
   (M20 planned it; it was never written). It: stamps both versions; builds Android (tests +
   APK) and desktop Release; publishes to a staging folder; builds the installer and the zip; writes
   `CHECKSUMS.txt` (SHA-256 + sizes); updates `update.json` (URLs on the GitHub pattern, hashes) and
   `RELEASE-NOTES.md` header; copies everything to `Linc prod` and cleans old builds (skipping locked
   folders); and **prints** the `git`/`gh` commands for push, release (small assets first, retries for
   the big ones) and the PR merge, but only runs them with `-Publish`. Re-runnable, fails loudly, no
   silent half-states. Use it for this release.
